# 🎨 Interactive CV - Vlad Pocris

A modern, interactive portfolio website showcasing skills, experience, and projects with smooth animations and a polished user experience.

## 🚀 [View Live Demo](https://vladpocris.github.io/InteractiveCV/)

---

## ✨ Features

- **📱 Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- **🎭 Interactive Sections** - Smooth animations and transitions for an engaging experience
- **🌙 Dark Mode Support** - Built-in theme switching with next-themes
- **📊 Dynamic Content** - Showcase education, experience, projects, and skills
- **📧 Contact Integration** - Email form powered by EmailJS
- **⚡ Fast & Modern** - Built with React, TypeScript, and Vite for optimal performance
- **♿ Accessible** - WCAG compliant with semantic HTML and proper ARIA labels
- **📈 SEO Optimized** - Meta tags, structured data, and optimized loading

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI + custom components
- **Form Handling**: React Hook Form + Zod validation
- **Data Fetching**: TanStack React Query
- **Animations**: CSS animations & transitions
- **Email**: EmailJS integration

## 📦 Getting Started

### Prerequisites
- Node.js 16+ and npm/pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/vladpocris/InteractiveCV.git
cd InteractiveCV

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm preview
```
