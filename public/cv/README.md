# CV Storage

Place your CV PDF file in this folder with the name: `Vlad_Pocris_CV.pdf`

## How to Update Your CV

1. Replace the `Vlad_Pocris_CV.pdf` file with your updated CV
2. Commit the changes to git
3. Push to GitHub
4. The site will be redeployed and the download button will automatically serve the new CV

## File Name

**Important:** The file must be named exactly: `Vlad_Pocris_CV.pdf`

The download button in the portfolio points to `/cv/Vlad_Pocris_CV.pdf` and will automatically download this file when clicked.
